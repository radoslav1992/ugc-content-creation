# Video Studio

The English port retains the source workflow: script → expressive speech → listen and approve → portrait/quality → avatar video → captions/export.

- ElevenLabs v3 speech: up to 1,500 characters including emotion tags; 3 credits per character.
- Optional emotion suggestions: up to five daily; the model must preserve original script text and may only insert supported tags.
- Avatar input: a completed single-voice recording of 5–60 seconds and an authorized JPG/PNG portrait.
- Low quality: WaveSpeed InfiniteTalk Fast, 300 credits per started second.
- Medium: fal Kling avatar standard, 900 credits per started second.
- High: fal Kling avatar pro, 1,800 credits per started second.
- Video is charged separately from speech. Failed video generation refunds video credits while retaining the audio.
- Processing continues in Workflows; signed-in users can return later and optionally receive completion/failure email.
- Captions support eight presets, per-word timing, color, size, position, aspect ratio, local templates, and SRT/VTT exports.
- Local MP4 export runs in the browser; background export uses the private renderer.

Provider IDs and legacy resumed-job routes remain inherited. Configure the required account keys and generate English samples before launch. See [Deployment](DEPLOYMENT.md).
